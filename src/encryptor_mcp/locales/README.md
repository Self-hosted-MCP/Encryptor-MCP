Translations of the pages (unlock, a vault's page, browsing and the control center), one file per language: `de.json`,
`ja.json`, `pt-BR.json` and so on. Each file maps the English text of a page (the key) to its translation (the value).
`{placeholders}` and HTML tags stay exactly as in English. The translations were made with AI.

What the tools tell AI apps stays in English: the AI answers the person in their own language.

Make or update a file: `encryptor-mcp translate <code>`. Check it: `encryptor-mcp translate --check <code>`.
More: docs/languages.md.
